# Demo Video Script – Joineazy Task 1

Keep the recording around 4–6 minutes.

## 1. Introduction (20 sec)
"This is my solution for the Joineazy Full Stack Internship Task 1. It is a role-based student, group and assignment management system. The frontend uses React and Tailwind, the backend uses Node and Express, PostgreSQL stores relational data, JWT handles authentication, and Docker provides reproducible setup."

## 2. Admin flow (90 sec)
- Login with admin account.
- Show dashboard statistics.
- Create an assignment: title, description, due date, OneDrive link.
- Explain all-student vs selected-group targeting.
- Show groups page.

## 3. Student flow (2 min)
- Login as student.
- Create a group.
- Add another registered student.
- Open Assignments.
- Open OneDrive link.
- Click **Yes, I have submitted**.
- Click **Confirm submission**.
- Show progress bar and confirmed state.

## 4. Admin verification (45 sec)
- Return to admin.
- Show analytics completion percentage.
- Open Groups & Submissions.
- Show student, group, assignment and confirmation timestamp.

## 5. Code / architecture (45 sec)
- Show separate frontend/backend folders.
- Briefly show Express routes, JWT middleware, PostgreSQL schema and Docker Compose.
- Mention parameterized queries, bcrypt password hashing, role middleware and database constraints.
