# Joineazy Round 2 Demo Script

## 1. Professor flow
1. Log in as `admin@joineazy.local` / `Admin@123`.
2. Show the polished professor dashboard.
3. Point out course cards, student count and analytics.
4. Create a course if needed.
5. Open Assignments and create a **Group** assignment for the course.
6. Create another **Individual** assignment.
7. Show the assignment list with course code, type and progress.

## 2. Student flow
1. Log in as `amit@joineazy.local` / `Student@123`.
2. Show enrolled course cards.
3. Click a course and open its assignment workspace.
4. Open the group assignment.
5. Show title, description, deadline, submission type and OneDrive link.
6. As group leader, click **Yes, I have submitted**.
7. Click **Confirm**.
8. Show the group progress moving to 100%.

## 3. Group-leader rule
1. Log in as another group member.
2. Open the same group assignment.
3. Show that the acknowledgement is already reflected for the member.
4. If testing before confirmation, the non-leader sees that only the leader can acknowledge.

## 4. Professor monitoring
1. Return to professor login.
2. Open Groups & submissions.
3. Show leader/member badges.
4. Filter submissions by **Pending** and **Confirmed**.
5. Return to Dashboard and show course analytics.

## 5. UI/UX points to mention
- Soft light background and semantic status colors.
- Responsive course-card grid.
- Loading states and validation feedback.
- Progress bars and badges.
- Subtle hover and progress animations.
- Role-based navigation and protected routes.
